# 🌍 Global Happiness Report Analysis

## 📌 Project Overview
This project analyzes the World Happiness Report dataset to understand what factors contribute to happiness in different countries. It explores the relationship between happiness scores, GDP per capita, social support, and healthy life expectancy using Python.

## 🎯 Project Objectives
- Find the top 10 happiest countries.
- Identify the 10 least happy countries.
- Calculate the average happiness score.
- Analyze the relationship between GDP per capita and happiness.
- Study the relationship between social support and happiness.
- Understand the relationship between healthy life expectancy and happiness.
- Visualize correlations between numerical variables.

## 📂 Dataset
**Dataset:** World Happiness Report 2019

The dataset contains information about countries, including:
- Country or region
- Happiness score
- GDP per capita
- Social support
- Healthy life expectancy
- Freedom to make life choices
- Generosity
- Perceptions of corruption

## 🛠️ Technologies Used
- **Python** – Programming language
- **Pandas** – Data cleaning and data analysis
- **Matplotlib** – Data visualization
- **Seaborn** – Statistical visualizations

## 📊 Project Visualizations
This project generates the following graphs:

1. Top 10 Happiest Countries
2. GDP vs Happiness Score
3. Social Support vs Happiness Score
4. Healthy Life Expectancy vs Happiness Score
5. Correlation Heatmap

## ⚙️ Installation

Install the required Python libraries using the following command:

```bash
pip install pandas matplotlib seaborn
```

## ▶️ How to Run the Project

1. Download or clone this repository.
2. Keep `happiness_analysis.py` and `2019.csv` in the same folder.
3. Install the required libraries.
4. Open the project folder in VS Code.
5. Run the following command in the terminal:

```bash
python happiness_analysis.py
```

## 🔍 Analysis Performed
- Checked for missing values.
- Removed duplicate rows.
- Filled missing numerical values with column averages.
- Sorted countries by happiness score.
- Calculated the average happiness score.
- Compared happiness with GDP, social support, and healthy life expectancy.
- Calculated correlations between numerical variables.
- Created a heatmap to visualize relationships between variables.

## 📝 Conclusion
This project helps explore how economic conditions, social support, and healthy life expectancy are associated with happiness in different countries. Data visualization and correlation analysis make it easier to understand patterns in the World Happiness Report.
